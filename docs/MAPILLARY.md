# Street-image acquisition pilot

Run from repository root: `python tools/fetch_mapillary.py`. Paste the Mapillary client access token into the hidden terminal prompt (not into Git, chat, or a command line). Alternatively use the MAPILLARY_TOKEN environment variable. The default pilot covers central Haapsalu, selects up to 160 images with spatial/heading diversity, and saves photos and camera metadata locally. Use --metadata-only for inventory, --area city to extend after validation, --refresh to refresh cached catalogue. Source photos are ignored by Git. The script does not project textures yet. The coverage_report.json records actual downloads and metadata completeness. Preserve original contributors and image IDs, and comply with Mapillary API terms, CC BY-SA attribution and share-alike obligations for any published texture assets. Never upload a raw cache or credentials to the public repo. API behavior and coverage require a real token to test.

The next reconstruction checkpoint is matching actual camera poses to existing EPSG:3301 geometry, correcting projection and testing photo-derived facades in a representative central street before scaling. No game rebuild required for acquisition.

Discovery now uses public original and computed zoom-14 vector tiles instead of Graph bbox queries, which returned no results in the first pilot. Install `mercantile mapbox-vector-tile`. Empty catalogues are never reused. Use `--image-id <pKey>` to diagnose a known visible image directly. Tile/Graph API access is not live-tested by the connector.

The second pilot found 13,649 IDs, but all 160 metadata requests returned HTTP 400. The per-image request incorrectly included is_pano (a vector-tile field; camera_type is the documented Graph equivalent). The downloader now authenticates as in the SDK example, preflights id,thumb_2048_url, negotiates optional metadata fields if needed, logs sanitized API messages, reuses the nonempty catalog and stops after five consecutive failures. Run `python tools/fetch_mapillary.py --max-images 5` first. No live Graph verification yet.
